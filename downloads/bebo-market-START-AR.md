# ابدأ هنا — ببو ماركت

هذه النسخة تحتوي رقمك **+249991974489** للواتساب والمكالمات، ورابط **https://www.facebook.com/Babo0Nasir**.

1. فك ZIP في مجلد جديد، واترك النسخة القديمة محفوظة.
2. لعرض الشكل فقط على جهازك، ثبّت Node.js LTS ثم شغّل **preview.bat**. افتح الرابط الذي يظهر في النافذة.
3. لتفعيل حفظ الطلبات والإدارة، أنشئ **مشروع Firebase مستقلًا للسوق**، ثم اتبع قسم «التفعيل الحقيقي» في **README-AR.md**.
4. شغّل **setup-firebase.bat** لربط تطبيق Web بمشروعك، وأنشئ قائمة بريد الإدارة من Firebase Console حسب الدليل.
5. شغّل **deploy.bat** للنشر على Firebase، أو اتبع قسم GitHub Pages في الدليل لنشر الواجهة هناك مع حفظ البيانات في Firebase.
6. ادخل الإدارة، وانشر الكتالوج الأولي، ثم راجع المتاجر والأسعار ورسوم التوصيل واحذف الأمثلة. أوقف الوضع التجريبي عندما تكون البيانات حقيقية وجاهزة.

الطلب يُسجّل برقم مرجعي ثم يظهر رابط لمتابعته في واتساب؛ يرسل العميل الرسالة بنفسه. تبقى السلة محفوظة حتى يختار تفريغها. في الإدارة تظهر الطلبات الفعلية ويمكنك تغيير الحالة والمتاجر والأسعار وإعدادات التواصل.

**مشروع الكلية dongola-eng منفصل؛ لا تستخدمه لببو ماركت.** هذه الملفات لا تغيّر المشروع المنشور حتى تربط مشروع السوق وتنفّذ النشر بنفسك.
